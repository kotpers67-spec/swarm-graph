**SwarmGraph** — высокопроизводительное автономное Windows-приложение на базе **Tauri v2 + Rust + React 19** для визуализации, мониторинга и отладки мульти-агентных систем, роев (`/swarm`) и субагентов в реальном времени.

---

## 🚀 Основные возможности

### 1. Мульти-платформенность и поддержка любых агентов
- **Google Antigravity** (автоматический мониторинг `brain` и `.system_generated/swarm`).
- **Claude Code** (мониторинг сессий Anthropic CLI `~/.claude/projects`).
- **OpenAI Codex** (мониторинг сессий Codex CLI `~/.codex/sessions`).
- **Кастомные агенты**: поддержка добавления неограниченного числа пользовательских папок сессий с индивидуальным переименованием каждого агента (например, `@mari`, `@tester`).
- **Мульти-выбор чекбоксами**: возможность объединять сессии из разных платформ в единый список с контрастными цветными бейджами `[Antigravity]`, `[Claude Code]`, `[Codex]`, `[Кастомный]`.

### 2. Подключение любого агента через системный промпт (1 клик)
- Кнопка **«Подключить агента»** в шапке окна.
- Встроенный генератор готового системного промпта на русском языке для Claude Code, OpenAI Codex и кастомных скриптов.
- Подключение к общей шине сообщений (`board.jsonl`) и автоматическая регистрация на интерактивном холсте графа.

### 3. Инспектор шагов в стиле Cursor / IDE
- Отображение действий агентов строго в первом лице настоящего времени:
  - `Выполняю manage_task >`
  - `Читаю api.ts >`
  - `Редактирую TS server-manager.ts +1 -1 >`
  - `Создаю component.tsx +120 -0 >`
  - `Анализирую параметры задачи >`
  - `Отвечаю пользователю >`
- Цветные бейджи расширений файлов (`TS`, `PY`, `RS`, `JSON`, `CSS`), темные капсулы имён файлов, цветные диффы строк (`+N` зелёным, `-M` красным).
- Плавное раскрытие аккордеона по клику: просмотр полного промпта, ответа модели, входных/выходных токенов и времени.
- Встроенный переключатель языка `[RU] EN` (русский включён по умолчанию).

### 4. Компактная группировка оркестра роя
- Кнопка **«Компактно»** в шапке и **«Собрать»** на тулбаре холста.
- Умный алгоритм собирает 50+ агентов в упорядоченную матрицу (6 колонок) без гигантских пустот и наложений.

### 5. Мгновенный отклик перетаскивания окна (0 мс лага)
- Реализован нативный вызов `getCurrentWindow().startDragging()` в Tauri v2 без конфликтов WebView2, обеспечивающий идеально плавное перемещение безрамочного окна по экрану.
- Двойной клик по шапке разворачивает / восстанавливает окно.

### 6. Встроенный автопереводчик сообщений и промптов
- Локальный перевод текстов на русский язык в фоновом режиме.
- Маскирование кода, ссылок и путей Windows для защиты синтаксиса при переводе.
- Отказоустойчивый fallback на Google Translate API (`clients5`).

### 7. Таймлайн воспроизведения (Replay) и Экспорт
- Пошаговое воспроизведение истории сообщений роя со скоростями 0.5x, 1x, 2x, 4x и режим LIVE.
- Экспорт графа в автономный HTML, интерактивный JSON, а также запись видео (MP4 / GIF) через встроенный модуль FFmpeg.

## 📦 Быстрый запуск (Portable)

Скачайте готовый архив из [Releases](https://github.com/kotpers67-spec/swarm-graph/releases):
1. Распакуйте `SwarmGraph-portable-v1.0.0.zip`.
2. Запустите `SwarmGraph.exe`.
3. Приложение автоматически подхватит активные сессии роя из папки Antigravity brain или подключённых каталогов.

## 🛠 Сборка из исходников

### Требования
- **Node.js** >= 20
- **Rust** >= 1.80 (с таргетом `x86_64-pc-windows-msvc`)
- **Tauri CLI v2**

### Установка зависимостей
```bash
npm install
```

### Запуск тестов
```bash
npm test
```

### Запуск в режиме разработки
```bash
npx tauri dev
```

### Сборка релизного бинарника
```bash
npx tauri build --no-bundle
```
Скомпилированный исполняемый файл будет доступен в `src-tauri/target/release/swarm-graph.exe`.
